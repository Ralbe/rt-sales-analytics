# Запуск в Windows

1. Установите Docker Desktop с поддержкой Linux-контейнеров и запустите его. Дождитесь готовности Docker.
2. Распакуйте архив. Откройте PowerShell в папке `rt-sales-analytics`, где находятся `docker-compose.yml` и этот файл.
3. Создайте настройки:

   ```powershell
   Copy-Item .env.example .env
   ```

   Перед использованием реальных данных замените `SECRET_KEY` длинной случайной строкой и измените пароли в `.env`. Для демонстрации оставьте `SEED_DEMO_DATA=1`; для пустой рабочей базы — `0`.
4. Запустите:

   ```powershell
   docker compose up --build -d
   docker compose ps
   ```

5. Откройте [http://localhost:8080](http://localhost:8080). Первая сборка занимает несколько минут. Если страница ещё не открывается, проверьте состояние сервисов и сообщения:

   ```powershell
   docker compose logs --tail 100 api web nginx
   ```

Вместо шага 4 можно запустить `powershell -ExecutionPolicy Bypass -File .\start.ps1 -Detach`. Скрипт проверяет готовность Docker и запускает проект; автоматический ремонт Docker из прежней версии убран.

## Вход в демонстрационную базу

Логин: `admin@example.com`. Пароль: `Demo2026!`.

При первом входе сайт предложит добавить QR-код в TOTP-аутентификатор. Введите текущий шестизначный код из приложения. При следующих входах потребуется пароль и новый код. Если база существовала раньше, используются её учётные записи и настройки двухфакторного входа.

## Обновление существующей установки

Сохраните резервную копию базы и прежнюю версию проекта. Перенесите свой `.env` в новую папку, сохранив имя Compose-проекта и настройки подключения к прежнему тому. Затем выполните `docker compose up --build -d`.

API применяет миграции при запуске. Миграция `0015_archives_imports` добавляет версии отчётов и журнал импорта. Она не меняет существующие проекты. Обратная миграция отказывается удалять эти таблицы, если в них уже есть данные.

Остановить приложение: `docker compose stop`. Запустить снова: `docker compose start`. Не используйте `docker compose down -v`, если данные нужно сохранить.

Если порт 8080 занят, измените `HTTP_PORT` в `.env`, например на 8081, и снова выполните `docker compose up -d`. Открывайте адрес с выбранным портом.
