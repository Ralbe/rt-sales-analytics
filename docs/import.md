# Импорт проектов из Excel

Войти администратором → «Импорт проектов» → выбрать XLSX → указать лист, строку заголовков и признак НДС → «Проверить файл». Если заголовки отличаются, раскройте «Сопоставить столбцы» и повторите проверку. Кнопка «Импортировать проекты» доступна после успешной проверки.

Пример: `examples/projects-import.xlsx`. В нём заголовки находятся в строке 1 на листе «Список проектов». В исходном файле кейса используются заголовки в строке 3.

Обязательные столбцы: **Клиент**, **Описание проекта**, **Этап**. Название этапа должно соответствовать справочнику. Необязательные поля перечислены в форме сопоставления; основные — Сегмент, Услуга крупно, Менеджер, Год реализации, Дата, Столбец1 (ИНН), январь…декабрь.

Месячные суммы вводятся в **тыс. ₽**, до трёх знаков после запятой. Например, `1250` означает 1 250 000 ₽. Они создают строки выручки со статусом «прогнозное начисление»; сумма контракта определяется их суммой. Вероятность берётся из этапа. НДС не пересчитывается, выбранный признак применяется ко всему файлу. Для разных признаков НДС разделите загрузку на два файла.

Если ИНН отсутствует, клиент ищется по названию, а новому клиенту назначается технический идентификатор. Неизвестный сегмент заменяется на «Сегмент не указан» с предупреждением; новые услуги и менеджеры создаются по существующим правилам импорта кейса. Для новых менеджеров используется случайный пароль — доступ выдаёт администратор через «Пользователи».

Отрицательные суммы, неправильные годы, слишком длинные значения и неизвестные этапы нужно исправить перед подтверждением. Повторная загрузка пропускает уже созданные проекты. В журнале можно проверить результат; строки исходного файла указываются с их настоящими номерами.
