# Фирменный стиль

`rostelecom-partner-guidelines-2024.pdf` — официальный гайдлайн Ростелекома для партнёров, версия 2024 года. Получен 4 ноября 2026 года со [страницы фирменного стиля](https://www.company.rt.ru/about/identity/).

На странице 5 указаны Rostelecom Basis и замещающий Arial. Приложение использует Basis, если он установлен на компьютере пользователя, иначе Arial. Сам фирменный шрифт в архив не включён.
